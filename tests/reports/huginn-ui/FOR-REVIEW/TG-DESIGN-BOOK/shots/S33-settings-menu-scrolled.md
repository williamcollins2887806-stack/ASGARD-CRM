# S33 — settings-menu-scrolled

## 1. Мета
- Источник 828x1792 px, база 414 pt @2x, pt = px/2
- **Файл:** `REFS/S33.jpg`, RGB, JPEG (артефакты сжатия ±3–6 по каналу — все HEX ниже округлены по моде выборки).
- **Приложение:** Telegram iOS, русский UI, iOS 26 (Liquid Glass), тёмная тема OLED (фон `#000000`).
- **Экран:** вкладка «Настройки», список **прокручен вниз**: крупная шапка профиля (аватар) ушла под верх, в компактной навигации остался заголовок «Никита». Видна нижняя часть карточки подтверждения номера (строка «Изменить номер»), далее группы меню.
- **Status bar:** `09:53` + стрелка геолокации слева; по центру синий pill `TELEGRAM` с самолётиком; справа сигнал (1 из 4 полос белая), `LTE`, батарея **52** (жёлтая заливка = режим энергосбережения).
- **Tab bar:** плавающая стеклянная капсула (Контакты / Звонки / Чаты **52** / Настройки **!** — активна) + отдельный круглый FAB поиска справа.
- **Home indicator:** на кадре не обнаружен (по всей полосе y 1755–1791 px максимум яркости 8/255).
- Дословные тексты на кадре: `09:53`, `TELEGRAM`, `LTE`, `52` (батарея), `Никита`, `Изм.`, `Изменить номер`, `Мой профиль`, `Избранное`, `Недавние звонки`, `Устройства`, `QR-код`, `Папки с чатами`, `Уведомления и звуки`, `Конфиденциальность`, `Данные и память`, `Оформление`, `Энергосбережение`, `Выкл.`, `Язык`, `Русский`, `Контакты`, `Звонки`, `Чаты`, `52` (бейдж), `Настройки`, `!` (бейдж). Под стеклом/размытием — нечитаемые фрагменты (см. §10).

## 2. Иерархия слоёв
Снизу вверх по z:

1. **`.tg-screen`** — сплошной `#000000`, 414×896.
2. **`.tg-scroll`** (контент, прокручен):
   1. `.tg-group#phone-confirm` (низ карточки; верх уходит под навигацию) — размытые строки текста + строка-ссылка «Изменить номер»;
   2. `.tg-group` из 1 строки: «Мой профиль»;
   3. `.tg-group` из 4 строк: «Избранное», «Недавние звонки», «Устройства · QR-код», «Папки с чатами»;
   4. `.tg-group` из 6 строк: «Уведомления и звуки», «Конфиденциальность», «Данные и память», «Оформление», «Энергосбережение · Выкл.», «Язык · Русский»;
   5. `.tg-group` (под таб-баром, частично): строка с фиолетовой иконкой (размытый текст, похоже «Telegram Premium») и строка с оранжевой иконкой (обрезана снизу).
3. **`.tg-edge-top`** — scroll-edge effect iOS 26: размытие + затемнение контента под status bar и навбаром (0 → ~112 pt).
4. **`.tg-edge-bottom`** — такое же затемнение под таб-баром (низ кадра, контент тусклый до ~28 %).
5. **`.tg-navbar`** (без фона, плавающие стеклянные контролы): круглая кнопка QR слева, заголовок «Никита» по центру, pill «Изм.» справа.
6. **`.tg-status-bar`** — системный слой (время, TELEGRAM-pill, сигнал, LTE, батарея).
7. **`.tg-tabbar`** — стеклянная капсула с 4 вкладками + выделенный pill активной вкладки.
8. **`.tg-search-fab`** — отдельный стеклянный круг с лупой.

## 10. Неуверенности
- **Размытые тексты под top-edge:** вверху (y ≈ 0–30 pt) видна строка тела карточки, на уменьшенной копии похожая на «…можно указать … номер телефона.»; на уровне навбара — синяя строка вида «…авить +7 916 0… …» (вероятно «Оставить +7 916 …», номер не читается). Дословно не переписываю — блюр не даёт прочитать.
- **Строки под таб-баром:** первая — фиолетовая иконка и белый текст-силуэт, похоже «Telegram Premium» (не 100 %); вторая — оранжевая иконка, текст начинается на «М…», справа число, начинающееся на «10…»/«100» и шеврон — обрезано и затемнено, не читается.
- **Акцентный синий** (ссылка ≈ `#6C88D8`, активная вкладка ≈ `#5880D0`/`#6888C8`) — заметно бледнее типового акцента iOS/Telegram (`#3E88F7`/`#0A84FF`); причина может быть в JPEG-размытии тонких штрихов, top-edge затемнении и стекле. Для реализации разумно брать системный акцент и проверять по кадру.
- **Бейджи** `≈ #D4604C` — тоже приглушены относительно системного `#FF3B30`/`#FF453A` (стекло + JPEG).
- **Правая граница капсулы** (≈ 320.5 pt) и зазор до FAB (~9.5 pt) определены по размытому краю стекла, погрешность ±1–1.5 pt; инсет выделенного pill (≈ 3 pt) — ±1 pt.
- **Радиус плитки иконки** ≈ 7 pt — по профилю угла на одной плитке («Конфиденциальность»), squircle; ±1 pt.
- **Радиус карточек 26 pt** — по профилю угла (continuous curve), ±2 pt; точный радиус для многострочных групп может быть 24–26.
- **Параметры blur/затемнения** scroll-edge и стекла (blur 8 / 20 px, alpha 0.72–0.75) — оценка по яркостям, не прямой замер.
- **Тень** под стеклом почти не детектируется на чёрном фоне — значения в CSS ориентировочные.
- **Размеры шрифтов** выведены из cap-height с порогом бинаризации (JPEG срезает антиалиасинг), погрешность ±0.5–1 pt; начертание «Изм.» (Semibold vs Medium) не различимо уверенно.
- Home indicator отсутствует на кадре — либо скрыт, либо слился с затемнённым низом (яркость ≤ 8/255).
