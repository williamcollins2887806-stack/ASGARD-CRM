# S15 — chat-search-ios-dark

## 1. Мета
- **Источник 828×1792 px, база 414×896 pt @2x, pt = px/2.** (Файл: `REFS/S15.jpg`. Все размеры ниже — в pt базы 414; в скобках — px@2x, снятые Pillow по оригиналу.)
- **Устройство:** iPhone 414×896 pt @2x (класс XR / 11), iOS 26 (Liquid Glass: плавающие стеклянные капсулы, клавиатура со скруглённым верхом).
- **Приложение:** Telegram iOS, тёмная тема, фон чата — чёрный с doodle-паттерном.
- **Сцена:** групповой чат в режиме **«Искать в чате»**: вверху капсула поиска + круглая кнопка закрытия, внизу капсула фильтров поиска (по дате / по участнику), поднята системная клавиатура (русская раскладка, return-клавиша = синяя «лупа»).
- **Контент (сверху вниз):** хвост входящего сообщения от «OB» с реакциями (уходит под scrim статус-бара) → исходящее фиолетовое (3 строки, 18:57, прочитано) → плашка «Непрочитанные сообщения» → дата-пилюля «Сегодня» → входящее от «лиза Асгард» с цитатой-ответом (09:32) и аватаром.
- **Статус-бар:** 09:54 + стрелка геолокации, синяя пилюля «TELEGRAM» по центру (приложение использует геопозицию в фоне), сигнал, LTE, батарея жёлтая (режим энергосбережения) «51».

## 2. Иерархия слоёв
Снизу вверх (z-order):

1. **Wallpaper** — `#000000` + doodle-паттерн тонкими фиолетово-серыми линиями (едва видимыми).
2. **Лента сообщений** (скролл) — полная ширина 414 pt, контент уходит под верхний scrim и под клавиатуру.
   1. Входящий bubble «OB» (обрезан сверху) + аватар OB + капсула реакций.
   2. Исходящий bubble (фиолетовый, хвост справа снизу).
   3. Плашка «Непрочитанные сообщения» (edge-to-edge).
   4. Дата-пилюля «Сегодня».
   5. Входящий bubble «лиза Асгард» (имя → цитата → текст → время; хвост слева снизу) + аватар.
3. **Верхний scroll-edge scrim** — чёрный градиент 0 → ~110 pt, затемняет контент под статус-баром и капсулой поиска (текст «Действуем с…/подписываем оставшиеся акты, я» читается тускло-серым).
4. **Поисковый хром (плавающий, без подложки-панели):** капсула поиска (стекло) + круг «×» (стекло).
5. **Статус-бар iOS.**
6. **Капсула фильтров поиска** (стекло) — над клавиатурой слева.
7. **Системная клавиатура iOS 26** — лист со скруглёнными верхними углами: строка подсказок (с 2 разделителями) → 4 ряда клавиш → ряд глобус / микрофон.

Home indicator на кадре **не виден** (низ клавиатуры — сплошной `#161618`).

## 6. Иконки/контролы
- **Лупа в поле поиска:** контур ~17 pt, штрих ~1.5 pt, `#8A8A8C`, центр (39.5, 78).
- **Курсор:** 2×20 pt, `#5B86D4`, со скруглёнными концами; стоит перед плейсхолдером → поле пустое, в фокусе.
- **Кнопка закрытия:** отдельный стеклянный круг Ø44 (не внутри поля), глиф «×» 17.5 pt, штрих ~2 pt, `#FFFFFF`.
- **Реакции на «OB»:** капсула с 👌 (~20 pt) и кастомной реакцией-картинкой (круг ~22 pt).
- **✓✓ «прочитано»:** две галочки ~14.5×10 pt, `#CB95FF`, справа от времени.
- **Цитата:** вертикальная полоса 3 pt `#B35855` + красноватая подложка, без иконки.
- **Капсула фильтров:** 2 контурные иконки ~22 pt, штрих ~1.5 pt, белые: «календарь с лупой» (поиск по дате) и «силуэт с лупой» (поиск по участнику). Обе в покое (без акцентной подсветки).
- **Клавиатура:** Shift — залитая стрелка вверх; Backspace — контур «⌫»; эмодзи — залитый смайлик; return = **синяя клавиша с белой лупой** (~20 pt), а не текст; глобус ~27 pt и микрофон ~28 pt — белые, без подложки, под рядами клавиш.
- **Строка подсказок:** пустая, видны только 2 разделителя.
- **Статус-бар:** стрелка геолокации после времени; синяя пилюля с логотипом-самолётиком и надписью TELEGRAM; 4 полоски сигнала (2 яркие, 2 тусклые); «LTE»; жёлтая батарея.

## 7. Тени / бордеры / разделители
- **Стеклянные капсулы** (поиск, «×», фильтры): кромка 1 px@2x (0.5 pt) сверху/по контуру `rgba(255,255,255,0.13–0.14)`, к низу гаснет → эффект Liquid Glass. Явной drop-shadow на чёрном фоне не видно; используем `box-shadow: 0 4px 16px rgba(0,0,0,0.35)` для отрыва от контента.
- **Пузыри:** без теней и обводки; объём только за счёт заливки и радиуса 16 + хвост.
- **Цитата:** без обводки; полоса 3 pt слева, обрезанная скруглением блока 4 pt.
- **Плашка «Непрочитанные»:** сплошная заливка edge-to-edge, без линий сверху/снизу — сама работает как разделитель ленты.
- **Дата-пилюля:** без тени.
- **Клавиатура:** у листа нет верхней кромки/тени — отделён сменой цвета `#000` → `#161618` и скруглением 26 pt; клавиши плоские (без нижней тени, в отличие от iOS ≤ 17); разделители подсказок 1 pt `#343436`.
- **Верх ленты:** мягкий scroll-edge scrim (градиент чёрного) вместо твёрдой панели под поиском.

## 8. Состояния на кадре
- **Режим поиска включён:** обычная шапка чата и поле ввода сообщения скрыты; вместо них плавающая капсула поиска + «×» сверху и капсула фильтров снизу.
- **Фокус, пустой запрос:** курсор виден, плейсхолдер показан, результатов/счётчика нет.
- **Клавиатура:** поднята, русская раскладка, тип return = search (синяя лупа), подсказок нет.
- **Фильтры:** «по дате» и «по участнику» в покое.
- **Исходящее:** доставлено и прочитано (✓✓).
- **Граница непрочитанных:** плашка стоит между последним исходящим (вчера) и первым входящим (сегодня).
- **Входящее:** ответ на сообщение другого участника (цитата с автором), аватар показан, так как это последнее сообщение группы.
- **Скролл:** лента прокручена — верхнее сообщение «OB» уходит под scrim; аватар OB прилип к низу своего bubble.
- **Система:** геолокация в фоне (синяя пилюля), энергосбережение включено (жёлтая батарея).

## 10. Неуверенности
- **Насыщенность цветов имени и автора цитаты:** на тонких глифах JPEG смешивает цвет текста с фоном (`#D5B59C`…`#E3B68D`, `#A36266`). Истинные цвета темы, скорее всего, насыщеннее (≈ `#E8B07F` и ≈ `#D8696B`); для pixel-match брать семплы, для темы — уточнить по палитре peer-colors Telegram.
- **Стекло (blur/alpha):** на кадре за капсулами почти чёрный фон, поэтому сила blur (20–30) и альфа заливки (0.88–0.92) не измеримы — нужен кадр, где под капсулой есть светлый контент.
- **Хвосты пузырей:** форма хвоста по краю измерена грубо (тело + ~2.5 pt наружу в нижних ~6 pt); точный path Telegram не восстановлен.
- **Радиус скругления листа клавиатуры (~26 pt):** подобран по 3 точкам профиля; на углах экрана накладывается скругление дисплея.
- **Кегли:** выведены из ширины строк и шага строк (17/22.5 для текста — уверенно; 14.5 vs 15 для «Сегодня», 13 vs 14 для «TELEGRAM» — граница).
- **Капсула реакций и верх bubble «OB»:** частично под scrim и капсулой поиска — рамка приблизительная (±2 pt).
- **Doodle-паттерн:** конкретный SVG темы не извлечён; цвет и альфа линий — оценка.
- **Правый край капсулы фильтров (88 pt):** по кропу; на правом скруглении шум JPEG ±1 pt.
- **Home indicator:** на кадре отсутствует (скриншот iOS) — в реальном UI он поверх нижних ~34 pt клавиатуры.
