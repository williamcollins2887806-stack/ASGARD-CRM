## 10. Неуверенности

1. **Размеры шрифтов** оценены по кап-высоте на JPEG: абзац 15 или 16 pt (кап 11 pt), «Изменить фотографию» 15 pt
   (кап 10.5) против «Изменить номер» 16–17 pt (кап 11–11.5) — разница может быть артефактом порога/антиалиаса.
2. **Синяя капсула «TELEGRAM»** в статус-баре — системный индикатор; точная причина (геолокация, запись/трансляция,
   возврат в приложение) по кадру не определяется.
3. **Щит с «1»** рядом с номером — назначение не ясно (возможно, бейдж/эмодзи-статус); глиф внутри читается как «1».
4. **Прозрачность и blur стекла** (кнопки навбара, таб-бар, поиск) — восстановлены обратным счётом по цвету, не по
   реальным параметрам: alpha кнопок ≈ 0.75–0.8, blur таб-бара ≈ 10–15 pt — оценка.
5. **Круг поиска**: по замеру 66 × 64 pt; вероятно, это 64 pt круг + светлый ободок/антиалиас по горизонтали.
   Левый край капсулы таб-бара (≈17 pt) замаскирован красным размытым контентом — ±1 pt.
6. **Текст под таб-баром** («Мой профиль» с красной иконкой) прочитан по размытому изображению — может быть неточен.
7. **Радиус карточки 2** ≈ 26 pt (continuous corner); при squircle-скруглении «эквивалентный» CSS-радиус мог бы быть 24–28 pt.
8. **Неравномерные центры вкладок** (63.5 / 138 / 199 / 271.5 pt) — замер по подписям; иконки/подписи могут
   центроваться внутри неравных слотов из-за пилюли активной вкладки.
9. **Пилюля активной вкладки**: верх/низ (816/872 pt) определены по порогу яркости, ±1 pt.
10. Цвет акцента на тонком тексте сильно зависит от антиалиаса: ядро ≈ `#6488EB`, видимое среднее ≈ `#5A7CD1`.
