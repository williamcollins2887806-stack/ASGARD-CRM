# S30 — chat-album-live-location

## 1. Мета
- **Источник 828×1792 px, база 414 pt @2x, pt = px/2.** Устройство iPhone 414×896 pt (класс XR / 11, с чёлкой). Все размеры — в pt базы 414, в скобках — px исходника.
- Приложение: Telegram iOS, тёмная тема, стиль Liquid Glass (iOS 26): сплошных navbar / панели ввода **нет**, все контролы — плавающие стеклянные «пилюли» и круги поверх обоев.
- Экран: личный чат «Моя ❤️ 🍭», статус «был(а) недавно». Активна **трансляция геопозиции** от текущего пользователя («Вы»): синяя пилюля «TELEGRAM» в статус-баре + стеклянная плашка под шапкой.
- Лента сверху вниз: исходящий **альбом 3×2 фото** (верхний ряд уходит под плашку геопозиции), время «11:46 ✓✓» на бейдже → исходящий текст «Я какаю и выходим 14:02 ✓✓» → дата-разделитель «29 сентября» → входящее медиа: **вертикальный скриншот Instagram Reels** (чёрный фон), время «11:49» поверх картинки без видимого бейджа.
- Обои: фото (пара, объятия / руки), сильно мягкое; слева и в центре почти чёрное, справа — тёплый беж и белая ткань.
- Метод замера: Pillow — bbox глифов по порогу яркости, профили яркости по строкам/столбцам (поиск светлого ободка стекла), медиана / «самые яркие N пикселей» для цвета текста, autocontrast-зумы ×2…×5 с линейкой. Точность краёв ±1 px (±0.5 pt), у стеклянных краёв и размытых бордюров ±2 px (±1 pt). JPEG с цветовой субдискретизацией: тонкие цветные линии (1 pt) читаются десатурированными.

## 2. Иерархия слоёв
1. **Обои** — фото на весь экран 414×896, `background-size: cover`, без узора/паттерна.
2. **Лента сообщений** — колонка пузырей; верх альбома прокручен под шапку и плашку геопозиции (снизу запаса нет — лента «прижата» к низу, последний элемент заканчивается над панелью ввода).
3. **Status bar** (0–44 pt): время + стрелка геолокации, синяя пилюля «TELEGRAM» (системный индикатор фонового использования геолокации), сеть / «LTE» / батарея. Фона нет — прозрачно поверх обоев.
4. **Шапка — три независимых стеклянных элемента**: пилюля «‹ 52», центральная пилюля «имя + статус», круглый аватар.
5. **Плашка «Трансляция геопозиции»** — отдельная стеклянная капсула под шапкой (с боковыми отступами, не во всю ширину).
6. Внутри ленты: бейдж времени альбома (тёмное полупрозрачное стекло поверх фото), капсула даты.
7. **Панель ввода — три независимых стеклянных элемента**: круг «скрепка», капсула поля «Сообщение» (внутри справа иконка стикеров), круг «микрофон».
8. Кнопки «вниз», home indicator, клавиатура — на кадре **отсутствуют**.

## 10. Неуверенности
- **Верх альбома не виден** (скрыт под плашкой геопозиции/шапкой): число рядов (видно 2 → 6 фото), высота верхнего ряда и верхние углы — не подтверждены. Если верхний ряд равен нижнему (132.5), верх альбома ≈ y 91.
- Высота стеклянных элементов шапки 44 pt и диаметр кругов ввода 39–40 pt — измерены по внешней кромке светлого ободка; без ободка возможно 43 / 39 pt (±1 pt).
- Параметры стекла (α ≈ 0.63, C ≈ `#23221E`) — модель по 5 парам «внутри/снаружи», но фон под стеклом размыт, поэтому «снаружи» ≠ точный фон под пикселем; радиус backdrop-blur из кадра не измерим.
- Бейдж времени у медиа «11:49» на чёрном фоне не различим — есть ли там полупрозрачная подложка (как у «11:46»), по кадру не определить.
- Кант вокруг входящего медиа (`#1A1A1A`…`#212121`) трактован как фон входящего пузыря; реального входящего текстового пузыря на кадре нет для сверки цвета.
- Цвет рамки альбома десатурирован JPEG (тонкие 2-px линии); принят равным цвету пузыря `#894DE9`.
- Кегли подзаголовка, строк плашки и даты (12–13 / 10–11 / 13 pt) выведены из высоты глифов по порогу; JPEG и порог «съедают» ≈1 px, погрешность ±0.5–1 pt; начертание даты (Medium vs Semibold) на глаз.
- Количество «волн» в иконке трансляции (2 дуги с каждой стороны) и форма иконки стикеров — по зуму ×2, мелкие детали могут быть размыты.
- Время «14:02» `#D09CFF` — замер по ярким пикселям тонкого глифа; реальный цвет может быть чуть светлее/прозрачнее.
