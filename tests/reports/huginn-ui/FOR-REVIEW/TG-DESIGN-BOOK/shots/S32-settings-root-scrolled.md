# S32 — settings-root-scrolled

## 1. Мета

- Источник 828x1792 px, база 414 pt @2x, pt = px/2
- Файл: `tests/reports/huginn-ui/FOR-REVIEW/TG-DESIGN-BOOK/REFS/S32.jpg` (JPEG, лёгкие артефакты сжатия: цвета ±4 по каналу).
- Экран: Telegram iOS, вкладка «Настройки» (корень), тёмная тема, iOS 26 Liquid Glass. Список **прокручен вниз**: шапка профиля (аватар, имя, телефон) ушла под навбар, видна часть списка от «Уведомления и звуки» до «Возможности Telegram».
- Замеры сняты Pillow-профилями по оригиналу (вертикальные/горизонтальные профили, bbox по порогам яркости, моды цвета). Значения в pt = px/2; там, где край размыт стеклом/блюром, точность ±1 pt.

## 2. Иерархия слоёв

Снизу вверх:

1. **Фон страницы** — сплошной `#000000` (по всей высоте, поля слева/справа x<16 pt и x>398 pt — чистый 0,0,0).
2. **Скролл-контент (inset-grouped list)**:
   - карточка-секция «0» (выше кадра) — видна только её последняя строка «Папки с чатами» под статус-баром, сильно затемнена и размыта; низ карточки ≈ y 57.5 pt;
   - **Карточка 1** (6 строк): Уведомления и звуки / Конфиденциальность / Данные и память / Оформление / Энергосбережение / Язык;
   - **Карточка 2** (4 строки): Telegram Premium / Мои звёзды / Telegram для бизнеса / Отправить подарок;
   - **Карточка 3** (3 строки): Помощь / Вопросы о Telegram / Возможности Telegram.
3. **Scroll-edge-эффект сверху** (iOS 26): тёмная вуаль + блюр над контентом от y 0 до ≈116 pt (плато ≈75 % черноты до ~84 pt, далее градиент до 0 к ~116 pt).
4. **Навбар (без плашки, «плавающие» стеклянные контролы)**: слева круглая стеклянная кнопка с QR-иконкой, по центру заголовок «Никита», справа стеклянная капсула «Изм.».
5. **Статус-бар**: «09:53» + стрелка геолокации слева; по центру синяя капсула «TELEGRAM» с самолётиком; справа сигнал, «LTE», жёлтая батарея «52».
6. **Таб-бар (плавающий, Liquid Glass)**: большая капсула с 4 вкладками (Контакты, Звонки, Чаты, Настройки) + отдельная круглая стеклянная кнопка поиска справа. Внутри капсулы — светлая «линза» выбранной вкладки «Настройки». Бейджи «52» (Чаты) и «!» (Настройки).

## 6. Иконки/контролы

- **Плитки строк**: квадрат 30×30 pt, радиус ≈7 pt (суперэллипс iOS), градиенты из §4, белый глиф ≈18–20 pt, заливной (filled) стиль.
- **Шеврон** «›»: 7×12 pt, обводка ≈2 pt со скруглёнными концами, `#646466`.
- **Кнопка QR**: стеклянный круг Ø44 pt; глиф — QR-код (три скруглённых квадрата-рамки в углах + точечный блок справа внизу), белый, ≈22 pt.
- **«Изм.»**: стеклянная капсула 61×44 pt с текстом (без иконки).
- **Таб-бар**:
  - «Контакты» — силуэт человека в залитом круге (белый, ≈22.5 pt);
  - «Звонки» — трубка (залитая, ≈22 pt);
  - «Чаты» — два перекрывающихся пузыря (≈30 pt шириной), сверху справа бейдж «52»;
  - «Настройки» — шестерёнка Telegram: синий зубчатый обод, внутри тёмный круг с белым/синим трёхлучевым «пропеллером» (≈22 pt), бейдж «!» справа сверху; вокруг бейджа тонкий тёмный вырез, отделяющий его от иконки;
  - «Поиск» — лупа, белая обводка ≈2 pt, ≈20.5 pt, в отдельном стеклянном круге Ø64.
- **Бейджи**: красная капсула высотой 17 pt (25 pt для «52»), круг 16 pt для «!»; текст белый, по центру.
- **Капсула «TELEGRAM»** в статус-баре: синяя, 92×22 pt, белый самолётик Telegram + надпись.
- **Батарея**: жёлтое тело с тёмными цифрами «52» внутри, справа серый «носик».

## 7. Тени / бордеры / разделители

- **Карточки**: без тени и без обводки — плоский `#1C1C1E` на `#000`.
- **Разделители строк**: 1 px (0.5 pt) `#3A3A3C`, от x 76 pt до 381.5 pt (справа обрезаны на 16.5 pt раньше края карточки, слева — под текстом, не под плиткой). На первой/последней строке секции разделителей нет.
- **Стеклянные контролы** (QR, «Изм.», таб-бар, поиск):
  - светлый внутренний кант сверху и слева 1–2 px (`#2E2E2E…#373737` ≈ `rgba(255,255,255,0.12–0.16)`), снизу и справа — затухающий/тёмный;
  - внешней тени на чёрном фоне не видно (замер: сразу за кантом `#000000`); на кнопках, лежащих над карточкой, лёгкое затемнение подложки по краю (≈`#141414`) — возможна мягкая тень/рефракция ≈1–2 pt.
- **Линза выбранной вкладки**: `#383838` без резкой обводки, край ≈1 pt мягкий.
- **Scroll-edge**: вуаль с блюром (оценка блюра ≈6–10 pt по размытию текста «Папки с чатами»), см. §4.
- Нижнего scroll-edge над таб-баром не видно: карточка 3 до y 806 pt остаётся `#1C1C1E` без затемнения.

## 10. Неуверенности

1. **Акцентный синий** активной вкладки замерен как ≈`#5880D0`, но это тонкие глифы в JPEG; истинный цвет Telegram-акцента может быть насыщеннее (ближе к `#3E88F7`/`#0A84FF`). Капсула «TELEGRAM» (крупная заливка) даёт `#3478F4`. Это надёжнее.
2. **Цвет значения справа** (≈`#B0B0B2`) светлее стандартного iOS secondaryLabel `#98989D`; возможно, это свой серый Telegram или эффект JPEG-резкости на пиках. Тело глифов `#AEAEB0…#B1B1B3`.
3. **Модель стекла** (`rgba(27,27,27,0.9)` + blur) выведена из двух подложек; реальный Liquid Glass включает рефракцию и specular-подсветку, которые на статичном кадре по чёрному фону почти не видны. Радиус блюра (6–12 pt) — оценка по размытию текста.
4. **Левый край QR-кнопки** (17 pt) и правый край «Изм.» (≈396 pt) определены по антиалиасному канту на тёмном фоне, ±1 pt; левый край капсулы «Изм.» (≈335 pt) — оценка по зум-кропу (кант сливается с подложкой).
5. **Профиль вуали scroll-edge** (плато 75 % до 84 pt, ноль к 116 pt) реконструирован по яркости карточки; точная форма кривой (linear/ease) не определяется.
6. **Сепаратор начинается с 76 pt**, а глифы заголовков — с 78 pt; вероятно, сепаратор выровнен по leading текстового контейнера (боковой отступ глифа ≈2 pt). В CSS заложено 60 px от края карточки (16 + 60 = 76 pt).
7. **Размеры шрифтов бейджей**, «TELEGRAM», «LTE» — оценки по cap-height (±1 pt); вес «Изм.» (Regular vs Medium) по кадру не различим.
8. **Иконка «Энергосбережение»**: детали заполнения батареи (цвет и доля сегмента) на 30 pt-плитке не читаются уверенно.
9. **Сигнал сотовой сети**: «1 яркое деление из 4» прочитано по зум-кропу, может быть градиентом яркости делений.
10. **Карточка 0** (над «Уведомлениями») видна только размытой; её состав (что «Папки с чатами» — именно последняя строка) выведен по шагу 52 pt и зазору 24 pt.
