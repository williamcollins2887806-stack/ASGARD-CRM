# S22 — shared-voice-list-dark

## 1. Мета
- **Платформа:** iOS, портрет; стиль iOS 26 (плавающие «стеклянные» контролы: круглая кнопка «назад» и сегмент-пилюля без классического nav-bar).
- **Приложение:** Telegram iOS, тема Dark (OLED, фон `#000000`).
- **Экран:** «Общие материалы» группы/чата → вкладка **«Голосовые»**: список голосовых сообщений в одной сгруппированной карточке (inset-grouped). Заголовок — название чата `АСГАРД: Замена факель…` (обрезано многоточием), подзаголовок — `15 голосовых сообщений`.
- **Исходник:** `REFS/S22.jpg`. **Фактический размер файла 473×1024 px** (уменьшенная копия, а не 828 px). Пропорция 0.462 = 414×896 pt. **Пересчёт: 1 px кадра = 414/473 = 0.8753 pt** (≈1.75 физ. px @2x). Все значения ниже — **pt**, в скобках — px кадра, где важно.
- **Состояние:** список проскроллен в начало (верх карточки виден), видно 12 полных строк + 13-я обрезана низом кадра. Ни одна строка не играет, нет выделения.
- **Над интерфейсом:** системная iOS-пилюля «✈ TELEGRAM» (возврат в приложение / индикатор), статус-бар 09:54, LTE, батарея 51 % в режиме энергосбережения (жёлтая).

## 2. Иерархия слоёв
z снизу вверх:
1. `.tg-screen` — заливка `#000000` на весь экран (нет nav-bar фона, нет blur-полосы).
2. `.tg-statusbar` — время + стрелка геолокации слева; сигнал, `LTE`, батарея справа.
3. `.tg-os-pill` — синяя капсула «✈ TELEGRAM» по центру над статус-баром (системный индикатор, не часть приложения).
4. `.tg-nav` (прозрачный):
   - `.tg-glass-btn.tg-back` — круг 44 pt с белым шевроном «‹».
   - `.tg-nav-title` (2 строки по центру экрана): заголовок + подзаголовок-счётчик.
5. `.tg-seg` — стеклянная пилюля-сегмент на всю ширину (4 вкладки: Медиа / Файлы / Голосовые / Ссылки) с подложкой `.tg-seg-thumb` под активной «Голосовые».
6. `.tg-list-card` — одна карточка `#1C1C1E` с радиусом ~24 pt, внутри 13+ строк `.tg-voice-row`:
   - `.tg-voice-play` — синий круг 40 pt с белым скруглённым треугольником;

   - Разделителей между строками **нет**.
7. Home-indicator в кадр не попал (кадр обрезан по низу списка).

## 6. Иконки/контролы
- **Back (`.tg-back`)**: круглая стеклянная кнопка 44 pt, шеврон SF Symbol `chevron.left`, weight semibold, ~17 pt по высоте символа (визуально 7.5×16 pt), белый.
- **Сегмент-контрол**: капсула-контейнер + скользящий thumb-капсула под активным пунктом; пункты не равные (ширина по контенту). Неактивные подписи тоже белые (без приглушения) — активность передаётся только подложкой.
- **Play-кнопка**: круг Ø40 `#3E88F7`, внутри белый треугольник `play.fill` 15×17 pt с мягко скруглёнными углами, оптически сдвинут вправо на ~1.3 pt. Нет прогресс-кольца, нет waveform в строке.
- **Статус-бар**: стрелка геолокации (`location.fill`) справа от времени; сигнал 4 бара (2 активных); `LTE` ~12 pt semibold; батарея — капсула ~27×13 pt с носиком справа, жёлтая заливка 51 % с цифрой внутри.
- **Пилюля TELEGRAM**: бумажный самолётик (outline/filled белый) + текст.
- Шеврона-«раскрыть» в строках, аватаров, чекбоксов — **нет**.

## 7. Тени / бордеры / разделители
- **Тени:** на чёрном фоне не различимы — `box-shadow` не нужен (либо очень мягкая `0 8px 24px rgba(0,0,0,0.5)` для стекла, визуально нулевая).
- **Стекло (back, сегмент):** тонкий светлый «блик» по верхнему краю — 1 px кадра ≈ **0.5–1 pt**, `#2B2B2B` на сегменте и `#222222` на кнопке против тела `#181818`; по нижнему краю слабее (`#1F1F1F`/`#202020`). Реализация: `box-shadow: inset 0 0.5px 0 rgba(255,255,255,0.12), inset 0 -0.5px 0 rgba(255,255,255,0.05)`. Backdrop-blur визуально не проверяем (под контролами чистый чёрный), для iOS 26 ожидается `blur(20–30px) saturate(180%)`.
- **Карточка:** без бордера и без тени, только заливка `#1C1C1E`.
- **Разделители между строками:** **отсутствуют** (вертикальный профиль между строками ровно `#1C1C1E` на x=300 и x=150 px).
- **Thumb сегмента:** без обводки, плоская заливка `#393939`.

## 10. Неуверенности
- **Разрешение:** исходник 473×1024 px, а не 828 px, как сказано в задаче; все pt получены масштабом ×0.8753 → погрешность ±0.5–1 pt на мелких размерах (шеврон, треугольник, обводки).
- **Измерено скриптом по пикселям (надёжно):** границы кнопки «назад», сегмента, thumb, карточки; шаг строк 57.0 pt (по 12 шагам); диаметр play 40 pt; X начала текста; цвета `#000000`, `#1C1C1E`, `#181818`, `#393939`, `#3E88F7`-семейство, отсутствие разделителей.
- **Оценено глазом / подгонкой:** радиус карточки 24 pt (подгонка дуги по 3 точкам, допуск 22–26); кегли шрифтов (выведены из высоты прописных/цифр: 17/13/15/16/14 pt, допуск ±1 pt); начертания (Semibold vs Medium для имени и подписей сегмента не различимы на JPEG); толщина шеврона 2.5 pt; скругление углов треугольника.
- **Стекло:** наличие и сила `backdrop-filter` не проверяемы — под контролами чистый чёрный. Цвет `#181818` может быть как прозрачным слоем стекла, так и плотной заливкой. Обводка-блик (1 px кадра) на JPEG могла частично быть артефактом сжатия, но видна стабильно сверху на обоих стеклянных контролах.
- **Подзаголовок строки:** пиковые `#A0A0A2` завышены резкостью JPEG; истинный цвет, вероятно, `rgba(235,235,245,0.6)` или `#8D8E93` — не различить.
- **Ширины сегментов:** восстановлены по центрам подписей; точная модель (равные или по контенту) — по thumb видно, что по контенту, но паддинги неактивных пунктов не наблюдаемы напрямую.
- **Тени** не видны на чёрном — значения в CSS условные.
