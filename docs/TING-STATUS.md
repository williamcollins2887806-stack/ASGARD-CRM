## Известные ограничения (не инциденты)

- iOS: нет демонстрации экрана, звонок засыпает в фоне.
- Android TV: эхо без гарнитуры зала (нет аппаратного AEC).
- 40 участников: не все с камерой — работает `max_video`.
- Корпоративные сети, разрешающие только TCP/443: нужен TURN/TLS на отдельном IP.
