# Тинг — матрица поддержки устройств

Дата: 2026-11-05
Правило: если устройство в колонке «Не поддерживается» — поддержка говорит это прямо,
а не «попробуйте ещё раз».

## Поддерживается

| Платформа | Минимум | Что работает | Ограничения |
|-----------|---------|--------------|-------------|
| Windows 10/11 | Chrome, Edge (актуальные) | камера, мик, экран, чат, запись, опросы | эксклюзивный захват камеры: закрыть Zoom/Teams |
| macOS | Chrome, Edge, Safari 16+ | камера, мик, экран (Chrome/Edge), чат | в Safari нет демонстрации экрана |
| Linux | Chrome, Firefox (актуальные) | камера, мик, экран, чат | нет системного шумодава ОС |
| Android | Chrome 100+ | камера, мик, чат, реакции | демонстрация экрана зависит от прошивки |
| iOS / iPadOS | Safari 16.4+ | камера, мик, чат | **нет демонстрации экрана**, фон усыпляет звонок |
| Android TV | Android 8+ (WebView 90+) | камера зала (USB), мик, просмотр | нет чата и шаринга с ТВ; эхо без гарнитуры |
| Телефон (dial-in) | любой | голос | нет видео, PIN добирается DTMF |

## Не поддерживается (и почему)

| Платформа | Причина |
|-----------|---------|
| Internet Explorer | нет WebRTC |
| Safari < 16 | нет нужных API медиа |
| Android < 8 | WebView без WebRTC-разрешений |
| Встроенные браузеры соцсетей (Instagram, VK in-app) | часто блокируют `getUserMedia` — открывать в системном браузере |
| iOS: звонок в фоне / экран заблокирован | ограничение WebKit; нужен native-клиент (волна 3) |
| iOS: демонстрация экрана | нужен ReplayKit-экстеншен в native-приложении |
| ТВ без WebView-обновлений (старые прошивки 2016–2017) | `getUserMedia` не проходит согласие разрешений |

## Как проверять новое устройство (5 минут)

1. Открыть `/ting/` в браузере устройства.
2. Разрешить камеру и микрофон.
3. Убедиться, что полоска микрофона двигается при разговоре.
4. Войти в тестовую комнату с ноутбука.
5. Проверить: видно/слышно в обе стороны, отключение и повторное включение камеры.
6. Зафиксировать модель и версию ОС в `tests/reports/TING-MANUAL-<дата>.md`.

## Что писать в поддержку при проблеме на устройстве

Модель, версия ОС, браузер и версия, сеть (офис/дом/LTE), что именно не работает.
Без этого тикет возвращается — «не работает» на 200 моделях не диагностируется.
