## Правила для агентов

Каждый агент должен:
1. Читать `DESIGN_SYSTEM.md` и `ARCHITECTURE.md` ПЕРЕД работой
2. Использовать ТОЛЬКО компоненты из `@/blocks`, `@/inputs`, `@/modals`
3. **Никаких заглушек** — CRUD на 100%, иначе НЕ начинать страницу
4. Структура: `pages/<PageName>/{index.jsx, api.js, ...}`
5. Подключать в `src/App.jsx` (Route)
6. Билд должен быть чистым в конце
7. После сдачи — обновить `MIGRATION_LOG.md`
