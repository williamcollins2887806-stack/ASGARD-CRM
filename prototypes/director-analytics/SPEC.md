# Дашборд руководителя — спека v3

Прототип: `prototypes/director-analytics/`
Запуск: `node prototypes/_serve.js` из корня репо → порт **8791** →
`http://127.0.0.1:8791/director-analytics/`

Офлайн-мок, без сетевых запросов. Русский интерфейс.

## Структура экрана

Три секции, все отрисованы сразу одна под другой (не табы), у каждой свой hero-ряд цифр.

### 1. Тендеры

Периоды: Месяц · Полгода · Год · Всё время.
Статусы реестра (6): рассмотрение · готовим · подались · выиграли · проиграли · отмена.

Hero-ряд: тендеров в периоде · сумма НМЦК · цена работ без НДС · конверсия.

Строка статуса: левая тонкая полоса тона, название, мета-строка (НМЦК + ближайший дедлайн), крупный счётчик, сумма справа.

### 2. Заявки

Статусы канбана (11, ровно как в CRM):
`new` Новые · `calc` Просчёт · `approval` Согласование · `kp_prep` КП готов · `sent` КП ушло ·
`addendum` Дозапрос · `win` Выиграно · `lose` Проиграно · `work` В работе · `done` Завершено · `trash` Корзина.

Hero-ряд: заявок в периоде · сумма в работе · выиграно · конверсия.

Отдельного раздела «Корзина» нет — это 11-я колонка, и сумма по ней не считается.

### 3. Работы

Активные · На паузе · Архив.

Hero-ряд: работ в периоде · портфель контрактов · средняя маржа · оплачено.

## Модальная карточка

Общее: центр экрана, ширина до 1120px, `max-height: 88vh`, липкая шапка (кикер + id, заголовок,
мета-строка), липкая полоса табов с подчёркиванием-индикатором, скроллится только тело.
Тело — две колонки: основной контент + правая колонка метрик (288px). На узком экране — одна колонка.

### Тендер — 6 табов

| Таб | Содержимое |
|---|---|
| Сводка | заказчик, ИНН, площадка + ссылка, извещение, НМЦК, цена работ без НДС, дедлайн с днями, реестр + tender_status, регион; кто ведёт (калькулятор / аналитик / РП). Справа: цена, дедлайн, статус |
| Просчёт РП | калькулятор + kind (TO/PM), цена работ без НДС, себестоимость, маржа %, решение, дата финализации, рекомендация |
| Смета | таблица 5–7 позиций (позиция, кол-во, сумма, себестоимость, маржа %) + итоги: без НДС / НДС 20 % / с НДС / маржа |
| Чек-лист | пункты с ✓/○ и датой выполнения либо сроком |
| Отчёт РП | текст заключения, автор, дата, бейдж submit/reject |
| Документы | список файлов с типом и размером |

`work_price` — **без НДС** (канон D-173). НДС начисляется сверху и показывается отдельной строкой.

### Заявка — 4 таба

| Таб | Содержимое |
|---|---|
| Сводка | AI-цвет + уверенность + summary, отправитель, канал, создана, дедлайн, статус, назначенный РП, документы, просчёт если есть, комментарий |
| Просчёт | таблица позиций и итоги, либо честная заглушка «просчёт ещё не создан» |
| История | мини-таймлайн переходов статусов с датой, автором и комментарием |
| Документы | список файлов |

### Работа — 5 табов

| Таб | Содержимое |
|---|---|
| Сводка | паспорт объекта (заказчик, объект, адрес, договор, РП, бригадир, старт, окончание, фаза), светофор сроков, причина паузы |
| Финансы | контракт / себестоимость / маржа / оплачено / остаток / расходы факт + два прогресс-бара |
| Табель | см. ниже |
| Бригада | кто, роль, ставка за смену, дни, заезд–выезд |
| Чекины | дата, тип, подтверждение, автор и примечание |

## Табель — новый дизайн

Три блока сверху вниз, читается без пояснений.

1. **Шапка с итогами**: человеко-дней · начислено · человек в бригаде · средняя ставка.
2. **Таблица по месяцам**: `Месяц | Дней | Ставка | Начислено`, строка «Итого за период».
   Месяцы без выхода людей приглушены и показывают прочерк, а не нули.
3. **Сводка по людям**: `ФИО (роль · заезд — выезд) | Дней | Ставка | Начислено`.
4. **График заезд → выезд**: горизонтальные полосы по месяцам окна, с осью месяцев.

Ставка месяца = начислено / дни. Суммы строк сходятся с итогом — проверено счётом.

## Токены и визуал

Один акцент — золото (`--gold`). Цвет держат только статусы (`tone-info`, `tone-blue`, `tone-warn`,
`tone-ok`, `tone-err`, `tone-muted`) и AI-разбор (зелёный/жёлтый/красный).

| | Тёмная | Светлая |
|---|---|---|
| Фон приложения | `#0B0D11` | `#E8ECF1` |
| Фон страницы | `#0E1116` | `#F4F6F8` |
| Поверхности | `#14181F` / `#191E26` / `#1F2530` | `#FFFFFF` / `#F7F9FB` / `#EFF3F7` |
| Текст | `#F2F4F7` / `#9AA4B2` / `#6B7684` | `#16191D` / `#56606E` / `#7A8494` |
| Акцент | `#D5A64A` | `#A67A1F` |

Типографика: Manrope для чисел и заголовков (display 30–34px, tracking −0.035em), Inter для текста.
Никаких фиолетовых градиентов, эмодзи в KPI и glassmorphism.

Движение: 140–220ms, `cubic-bezier(0.32, 0.72, 0.28, 1)`. Модалка — scale 0.975 → 1 + fade.
Индикатор периода и табов — сдвиг `left/width`. Есть `prefers-reduced-motion`.

## Мобильный слой

Управляется атрибутом `body[data-vp="mobile"]` и `.crm[data-vp="mobile"]`; медиазапросы — только
для proto-chrome.

- Липкая компактная шапка 48px (hash + аватар), без заголовка страницы.
- Периоды — горизонтальный скролл, без переноса.
- Статусы — чипы в горизонтальном скролле (счётчик сверху, название снизу), высота ≥44px.
- Карточки — одна колонка, суммы справа, мета-строки в одну строку с обрезкой.
- Нижний таббар (Главная / Тендеры / Заявки / Работы / Ещё), 56px, тач-цели ≥44px.
- Деталь — во весь экран телефона: стрелка «назад», кикер, заголовок, табы, скролл-тело.
- `overflow-x` не появляется: проверено замером `scrollWidth − clientWidth = 0`.

## Мок-объём

- 12 тендеров: у каждого 5–7 позиций сметы, чек-лист, просчёт РП, отчёт РП, документы.
- 12 заявок: покрыты все 11 статусов (у `new` две карточки), у 9 есть просчёт, у всех история.
- 9 работ: 4 активных, 2 на паузе, 3 в архиве; у каждой бригада и табель на 6 месяцев.

## Арифметика (проверено счётом)

- Сумма позиций сметы == `total_no_vat` — 12/12.
- Сумма себестоимостей == `cost_total` — 12/12.
- НДС == ровно 20 % от суммы без НДС, `total_with_vat == total + vat` — 12/12.
- `work_price` тендера == сумма сметы — 12/12.
- Маржа в % пересчитана из сумм — 12/12.
- Табель: 6 месяцев у каждой работы, дни в месяце ≤ 31, суммы по людям сходятся с итогом.
